# 陈安叙工作台 · 永久 APP 部署包

这个文件夹里就是你的工作台，已经配好了「每天自动更新」和「可安装成 APP」。  
下面只要照着做，就能拥有一个**永久网址**，并且能像 App 一样添加到手机/电脑桌面。

---

## 一、第一次发到 GitHub（5 步，全程网页点鼠标）

> 如果你还没有 GitHub 账号：先打开 [https://github.](https://github.com)
>
> [com](https://github.com) ，点右上角 Sign up，用邮箱注册一个（免费）。

1. 登录 GitHub 后，点右上角 **「+」→「New repository」**（新建仓库）。
2. **Repository name**（仓库名）随便起一个，比如 `workbench`。
3. 下面选 **Public**（公开，免费；选了私有也行但要额外一步）。
4. 先**不要**勾选「Add a README」，直接点 **Create repository**（创建）。
5. 进入新仓库后，点 **「Add file」→「Upload files」**，把**本文件夹里所有文件和子文件夹**  
   （`index.html`、`sw.js`、`*.json`、`.github`、`refresh_workbench.py`、`.nojekyll`）  
   全部拖进去，拉到最下面点 **Commit changes**（提交）。

## 二、开启「永久网址」（GitHub Pages）

1. 在仓库里点上方 **Settings**（设置）。
2. 左侧找到 **Pages**（页面）。
3. \*\*Source（来源）\*\*选 **Deploy from a branch**（从分支部署）。
4. \*\*Branch（分支）\*\*选 **main**（或 master，看你是哪个）→ 点 **Save**（保存）。
5. 等 1～2 分钟，页面会显示你的网址，形如：  
   `https://你的用户名.github.io/workbench`  
   这就是**永久网址**，24 小时在线。

## 三、变成「永久 APP」（添加到主屏幕）

- **手机**：用浏览器打开上面的网址 → 点浏览器菜单「**添加到主屏幕**」→ 起个名（如「安叙工作台」）。以后桌面上就有它了，点开就是全屏 App。
- **电脑**：用 Chrome/Edge 打开网址 → 地址栏右侧点「**安装**」图标（或菜单里「安装应用」）。

## 四、每天自动更新（不用你管）

仓库里的 `每日数据刷新` 工作流已经设好：**每天北京时间 08:00** 自动抓取最新热点/财经数据并提交，  
Pages 几分钟后自动更新，你打开就是当天新内容。

想立刻看一次更新？进仓库 **Actions** 标签页 → 点「每日数据刷新」→ 右上角 **Run workflow** → 跑完即可。

## 五、本地也能用

直接双击本文件夹里的 `index.html` 也能看（数据是你上次刷新时的）。想手动刷新，双击运行 `refresh_workbench.py` 即可。

## 六、注意事项

- 完全**免费**，用的是 GitHub 免费额度，不会扣费。
- 数据来自网上免费公开接口；偶尔某个接口维护时会自动回退到上次的数据，不会白屏。
- 仓库设为 Public 后，任何人有链接都能访问；内容不想公开就建 Private 仓库（Pages 同样可用）。
